# Power Platform Knowledge

Dieses Repository veröffentlicht den wöchentlichen **Power Platform Brief** als statische GitHub-Pages-Webseite.

## Inhalt

- Microsoft Power Platform
- Copilot Studio
- Dataverse
- Governance
- Application Lifecycle Management (ALM)
- Lizenzierung
- Managed Environments

Jede Ausgabe beantwortet:

1. Was hat sich geändert?
2. Warum ist das für Solution Architects relevant?
3. Was sollte gelesen, geprüft oder angepasst werden?

## GitHub Pages aktivieren

1. Repository öffnen.
2. **Settings → Pages** aufrufen.
3. Unter **Build and deployment** als Source **Deploy from a branch** auswählen.
4. Branch **main** und Ordner **/docs** auswählen.
5. Speichern.

Anschließend ist die Seite normalerweise unter folgender Adresse erreichbar:

`https://yoursolutionsai.github.io/PowerPlatformKnowledge/`

## Struktur

```text
docs/
├── index.html
├── .nojekyll
└── archive/
    └── YYYY-MM-DD.html
```

Neue Wochenbriefe werden als einzelne HTML-Dateien im Archiv abgelegt und auf der Startseite verlinkt.
